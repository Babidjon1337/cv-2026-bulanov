# Компьютерное зрение, 2026

Репозиторий с лабораторными работами курса [«Компьютерное зрение»](https://github.com/ykvnkm/computer-vision-course).

| № | Тема | Папка |
| --: | --- | --- |
| 1 | Среда, репозиторий и первый взгляд на данные | [lab01](lab01/) |
| 2 | Классическая обработка: фильтры, пороги, контуры | lab02 |
| 3 | Данные: разметка, дубликаты, разбиение, аугментации | lab03 |
| 4 | Классификация и перенос обучения | lab04 |
| 5 | Детекция объектов | lab05 |
| 6 | Сегментация и промптовые модели | lab06 |

## Запуск

Установите зависимости из `requirements.txt`. Инструкции по запуску каждой работы находятся в README соответствующей папки.
