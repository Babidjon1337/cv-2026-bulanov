## Как запустить

Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Linux или macOS:

```bash
source .venv/bin/activate
```

Затем установите зависимости:

```bash
pip install -r requirements.txt
```

Для загрузки данных варианта клонируйте репозиторий курса и запустите скрипт из его папки:

```bash
git clone https://github.com/ykvnkm/computer-vision-course.git
cd computer-vision-course
python data/get_data.py --variant 3
```

Порядок запуска каждой работы описан в README её папки.
